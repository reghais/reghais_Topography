# منصة علوم الأرض — الجيولوجيا العامة وعلم الخرائط

## البيانات التعريفية من المرفق

- المدرسة العليا للأساتذة بسطيف — مسعود زغار.
- مديرية التعليم والشهادات والتكوين المتواصل — قسم العلوم.
- الأستاذ: رغيس عزالدين.
- المقياس: الجيولوجيا العامة.
- المستوى: السنة الأولى علوم طبيعية — متوسط.
- السنة الجامعية: 2026/2027.

أُدرج شعار المؤسسة الأصلي من ملف Word دون إعادة توليده. لم تُدرج ورقة الغياب أو أسماء الطلبة أو أية بيانات حضور. استخدام الاسم والشعار لا يعني أن المؤسسة اعتمدت هذه المنصة رسميًا؛ راجع صلاحية استخدام الشعار واعتماد المحتوى قبل النشر العام.

## تشغيل الموقع

افتح index.html في متصفح حديث مثل Chrome أو Edge أو Firefox أو Safari. الملف مستقل ويحتوي على التصميم والشيفرة والمحتوى والشعار. لا يحتاج إلى Node.js أو npm أو React أو عملية بناء، ولا إلى اتصال بالإنترنت لوظائف التعلم الأساسية.

على بعض الهواتف قد تعرض مديرات الملفات HTML كمعاينة دون تشغيل JavaScript. افتحه في متصفح يدعم الملفات المحلية أو استخدم رابط الموقع بعد نشره. الحفظ المحلي قد يكون مقيدًا في التصفح الخاص أو عند فتح ملف محلي؛ تنزيل الملاحظات يوفر نسخة مستقلة عنها.

## نشره مباشرة على GitHub Pages

1. أنشئ مستودعًا أو استخدم مستودع الموقع.
2. ارفع index.html إلى **جذر المستودع**، لا داخل مجلد إضافي. يمكن رفع .nojekyll أيضًا.
3. احفظ الملفات على الفرع main (أو الفرع الذي تختاره للنشر).
4. من Settings → Pages اختر Source: Deploy from a branch.
5. اختر الفرع main والمجلد /(root)، ثم Save.
6. انتظر اكتمال نشر Pages وافتح الرابط الذي يظهر في Settings → Pages.

هذه النسخة لا تحتاج GitHub Actions للبناء. إذا كنت تستبدل مشروع React السابق، غيّر مصدر Pages من GitHub Actions إلى Deploy from a branch، وعطّل سير النشر القديم كي لا يعيد الكتابة فوق هذه النسخة. لا ترفع ملف ZIP نفسه؛ فك ضغطه وارفع الملف index.html. لا تفتح رابط عرض الشيفرة على github.com على أنه الموقع المنشور.

يمكن نشر الملف نفسه على أي استضافة مواقع ثابتة. لا يعتمد على اسم المستودع أو مسار خارجي.

## محتوى الموقع

- ستة دروس: قراءة الخريطة والمقياس؛ منحنيات التسوية؛ المقطع الطبوغرافي؛ الخريطة الجيولوجية والميل؛ الطيات والفوالق؛ منهجية العمل والتوثيق.
- أهداف تعلم وأمثلة محلولة وتمرين قصير وحل قابل للإظهار في كل درس.
- مختبر تضاريس: قمة منفردة أو قمتان وسرج أو منخفض، مع تغيير الفاصل الرأسي، وسحب A وB بالفأرة أو اللمس أو ضبط الإحداثيات بلوحة المفاتيح.
- مقطع طبوغرافي محسوب من 161 عينة على سطح رياضي اصطناعي؛ تنزيل الرسم PNG والبيانات CSV.
- محاكي طبقات مستوية: الميل الحقيقي والميل الظاهري والسماكة مع إظهار افتراضات النموذج وحالات عدم التحديد.
- أربع حاسبات مع رفض المدخلات غير الصالحة وإظهار الخطوات.
- عشرة أسئلة تقييم ذاتي مع تغذية راجعة ومراجعة للإجابات وإعادة المحاولة.
- مسرد من 16 مصطلحًا عربيًا–إنجليزيًا وبحث عام في الدروس والأدوات.
- وضع فاتح وداكن، طباعة القسم الحالي، حفظ تقدم القراءة والإجابات والملاحظات محليًا، وتصدير الملاحظات إلى ملف نصي.

## حدود علمية ووظيفية مهمة

المحتوى تعليمي، وليس محاضرات رسمية منسوبة إلى الأستاذ أو امتحانًا رسميًا. المحاكيات اصطناعية لا تمثل خريطة منطقة حقيقية؛ ولا تستخدم للملاحة أو حسابات التصميم الهندسي. علاقة السماكة مشروطة بسطح أفقي وطبقة مستوية وعرض أرضي عمودي على المضرب. الميل الظاهري له حالة غير محددة عندما يكون المستوى رأسيًا والمقطع موازيًا للمضرب. المبالغة الرأسية الفعلية في المقطع تظهر صراحة وقد تقل تلقائيًا لتجنب قص الرسم.

لا يوجد خادم أو حسابات أو رفع ملفات أو مزامنة بين الأجهزة. لا يُرسل الموقع رسائل ولا نتائج الطلبة. بيانات التعلم تُحفظ فقط في متصفح المستخدم. فتح المراجع الخارجية يتطلب الإنترنت؛ المراجع لا تُحمّل تلقائيًا.

## الصيانة والتعديل

يمكن تعديل الملف index.html بمحرر نصي يحفظ UTF-8:

- التصميم في كتلة style داخل head.
- بيانات الدروس والأسئلة والمصطلحات في window.COURSE_DATA.
- منطق الأدوات في كتلة script الأخيرة.
- اسم المدرسة والأستاذ يظهران في الترويسة والقائمة والمراجع والتذييل؛ احرص على اتساقها عند التعديل.

احفظ نسخة قبل التعديل، واختبر الملف في المتصفح بعده. لا حاجة إلى مكتبات خارجية. التنقل يستخدم أجزاء الرابط (#) لذلك تحديث الصفحة أو الرجوع لا يتطلب إعداد توجيه خاص من الاستضافة.
